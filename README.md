# 2.semEksamenProjekt
Opgave skrevet af Dennis, Nicolas og Dina (gruppe 5)

Til vores database har vi brugt: DB Browser for SQLite. (Programmet kan downloades på: https://sqlitebrowser.org/dl/ )
Vores public Git er https://github.com/NicolasHO-eadania/2.semEksamenProjekt
Det er en forudsætning, at Visual Studio (VS) er installeret på din computer (Programmet kan downloades her: https://visualstudio.microsoft.com/downloads/ )

Her er trinvis vejledning til at åbne databasen på din computer:

1. Klik på vores GitHub-link som derefter åbnes i VS
2. I vinduet "Solution Explorer", højreklik på "2.sem projekt.db" og kopier filstien "Copy full path"
3. Åbn en ny stifinder mappe på din computer
4. Indsæt den kopierede sti i adressefeltet og tryk Enter
5. Du kan nu vælge at åbne filtypen med "DB Browser for SQLite"
6. Øverst vises programnavnet "DB Browser for SQLite" med din lokale sti og dokumentnavnet på vores fil
7. Du nu har tilgang til vores database
